# 咩哞 · Mie & Mou 窑陶品牌与视觉资产规范

100% 原创矢量窑陶 IP 与双色视觉系统规范，用于 iOS 原生绘制、应用图标导出与官网配套呈现。

## 一、双子主视觉（Mie & Mou）

- **咩（Mie · 棉纸瓷羊）**：温润哑光白陶卷云轮廓配釉面微笑双眸，随旋律呼吸轻抬，代表松弛明亮的上方高音旋律线。
- **哞（Mou · 暖可可窑牛）**：厚重沉稳的可可陶身躯与新月弯角，代表承载低音根音与暖泛音的沉稳陪伴者；夜间自动切换柔和发光浅眸以保持暗背景清晰度。

## 三、应用图标规范与生成

- 由独立无外部依赖的 Swift / CoreGraphics 脚本 [`Tools/ip/render_kiln_app_icons.swift`](../Tools/ip/render_kiln_app_icons.swift) 生成全部三态通用图标：
  - `AppIcon-Light.png`（`1024×1024`，不透明 sRGB，棉纸日色底托）
  - `AppIcon-Dark.png`（`1024×1024`，不透明 sRGB，深靛夜色与暖金釉点）
  - `AppIcon-Tinted.png`（`1024×1024`，不透明 sRGB，深灰单色浮雕适配系统染色）
- 构图兼顾 1024px 主图细节与 29pt 极小缩略剪影识别度：环绕窑陶双子的三道立体同心驻波纹与底部赤陶/暖金定频珠形成唯一品牌识别印记。
