咩哞（Chimmo）隐私政策

生效日期：2026 年 11 月 21 日

1. 核心原则：不联网、不收集任何数据

咩哞（Chimmo） 是一款完全在您的设备本地离线运行的音乐创作与可视化应用。我们不设账号系统，不连接任何远程服务器，不包含任何广告、统计分析或第三方追踪 SDK。

2. 麦克风权限的使用

当您使用「轻哼捉珠」功能时，应用会向 iOS 系统请求麦克风访问权限。您哼唱的音频信号仅在设备本机内存中实时转换为音高与音珠，从不上传、不外发，也不会用于任何云端训练或个人身份识别。您随时可以在 iOS「设置 › 隐私与安全性 › 麦克风」中撤回该权限，撤回后仍可正常点按七只咩哞或观赏内置编曲标本。

3. 本地存储与导出

您在应用内创作或调整的旋律仅保存在您的设备本机。只有当您主动使用系统分享菜单导出 MIDI 文件时，文件才会通过您指定的系统方式分享。

4. 联系我们

如对本隐私政策有任何疑问，请通过 GitHub Issues 联系开发者。
