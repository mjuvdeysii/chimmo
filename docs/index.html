咩哞 · Chimmo

把脑海里的旋律唱出来、看得见。iOS 原生音乐可视化与零乐理脑放旋律复现器物（完全离线、无账号、无广告）。

咩哞七小只（调内 1–7 音级）

坐在矮木架上的七只哑光窑陶小偶分别对应当前调内的七个音级：1 陶诺（家）、2 豆叩（迈步）、3 拍咯（晴雨）、4 呜嘟（悬步）、5 壳咯（远望）、6 钵莫（怀旧）、7 叮尖（踮脚）。全员不说话，只用姿态、倾角、呼吸与微光回应真实发生的音乐。

核心功能与支持

  • 单音节轻哼捉珠：端侧离线将哼唱凝结为纸面陶珠，附带半透明幽灵备选珠一指微调。
  • 水面托底现代和声：向上托起水面即可铺开毛毡暖阳、透明水波、电影微光三种现代和声织体。
  • 16 首可拆解编曲标本：内置 8 首自编公版古典与 8 首原创现代技法标本，支持拆轨独奏与 0.5× 慢放。
  • 技术支持与反馈：如有任何问题或建议，请访问 GitHub Issues。
